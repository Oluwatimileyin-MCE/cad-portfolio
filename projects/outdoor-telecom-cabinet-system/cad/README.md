# CAD files

| File | Use |
|---|---|
| `outdoor-telecom-cabinet-system.f3d` | Editable Autodesk Fusion design with feature history, joints and section view |
| `outdoor-telecom-cabinet-system.step` | Neutral exchange file for any CAD tool |
| `outdoor-telecom-cabinet-system.stl` | Mesh of the full assembly |

STEP and STL are exported with the doors closed. The Fusion file holds the door joints (equipment cabinet 120°, battery cabinet 110°) and Section A-A. Drawings are in inches [mm]; the Fusion model is in centimetres internally.
