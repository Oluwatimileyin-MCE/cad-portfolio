# CAD files

| File | Use | Notes |
|---|---|---|
| `takeaway-container-750.step` | Import into any CAD tool | Two solids, `Base` and `Lid`, lid in the closed position. Units are millimetres. |
| `takeaway-container-750.f3d` | Edit in Autodesk Fusion | Fully parametric; change the values in the Fusion parameter table. |

There is no STL file. If you need one for 3D printing, export it from either file above (the model is in mm).

**Checks on the STEP file:** overall extents are x -95.8 to 108.0 mm, y -65.8 to 65.8 mm, z 0 to 54 mm (the 108 mm is the end of the thumb tab; the 54 mm is the top of the lid stacking ring).
