# START HERE - Modern Minimalist Stainless Steel Dining Set (SDS-100)

**Status:** Design complete; Rev A released.

1. **Open the model:** `cad/Dining_Set_Assembly.f3d` in Autodesk Fusion, or `cad/Dining_Set_Assembly.step` in any CAD tool. Single-part files: `cad/Dining_Table.step`, `cad/Dining_Chair.step`.
2. **Check the import:** units are millimetres, Z is up, floor at Z = 0. Table envelope 1200 x 750 x 750; chair envelope 430 x 483 x 900.
3. **Drawings:** `docs/drawings/` (A3 PDF, one sheet each for table, chair and set layout).
4. **Specification and BOM:** `docs/PRODUCT_SPECIFICATION.md`, `docs/BILL_OF_MATERIALS.csv`.
5. **Fabrication:** `docs/MANUFACTURING_NOTES.md`.
