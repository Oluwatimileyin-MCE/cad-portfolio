## Check the import

After opening the STEP or STL, the full set measures **1600 x 1775 x 830 mm**. The table measures 1600 x 900 x 750 mm and each chair 450 x 566 x 830 mm. Units are millimetres.

## Summary

Modern minimalist dining set: sintered stone top table on tapered AISI 304 stainless steel legs, with four wire-frame stainless steel chairs and upholstered seat pads. Satin brushed, warm-taupe PVD finish. Drawing No. SDS-100 (table SDS-T160, chair SDS-C45).
