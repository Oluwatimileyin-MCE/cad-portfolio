# CAD files

| File | Use |
|---|---|
| `orange-pi-zero-3-enclosure.f3d` | Editable Autodesk Fusion design. Dimensions are driven by `OPZ3_` user parameters (see `../data/design_parameters.csv`). |
| `orange-pi-zero-3-enclosure.step` | Neutral exchange file with the three bodies in assembly position. |

Coordinate system: origin at the centre of the cavity, X along the 96.4 mm length, Y across the 64.4 mm width, Z from the rear face (z = 0) to the lid. The rear feet extend to z = -3.
